How to read the evidence

Kernel architecture comes from the binary's PE machine field when its Windows service path can be resolved and read. Package targets come from INF decorations and do not prove which binary is loaded. “Observed” means no checks raised a flag; it does not certify hardware compatibility. Unknown evidence stays unknown.

Reports stay local. Raw instance IDs are replaced by a digest; names and driver metadata remain in exported reports. This tool does not install, disable, or change drivers.
